## التثبيت

### الخطوة 1: تحضير قاعدة البيانات

1. قم بإنشاء قاعدة بيانات جديدة:
```sql
CREATE DATABASE sick_leave_system CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

2. أنشئ مستخدماً لقاعدة البيانات:
```sql
CREATE USER 'sick_leave_user'@'localhost' IDENTIFIED BY 'your_secure_password';
GRANT ALL PRIVILEGES ON sick_leave_system.* TO 'sick_leave_user'@'localhost';
FLUSH PRIVILEGES;
```

### الخطوة 2: نسخ الملفات

```bash
# انسخ جميع الملفات إلى مجلد الخادم
cp -r /path/to/sick_leave_system /var/www/html/

# أو إذا كنت تستخدم XAMPP
cp -r /path/to/sick_leave_system C:\xampp\htdocs\
```

### الخطوة 3: تحديث إعدادات قاعدة البيانات

افتح ملف `sick_leave_enhanced.php` وحدث البيانات التالية:

```php
$db_host = 'localhost';      // عنوان الخادم
$db_user = 'sick_leave_user'; // اسم المستخدم
$db_pass = 'your_password';   // كلمة المرور
$db_name = 'sick_leave_system'; // اسم قاعدة البيانات
$db_port = 3306;              // منفذ MySQL
```

### الخطوة 4: إنشاء مجلد الشعارات

```bash
# أنشئ مجلد لتخزين الشعارات
mkdir -p /var/www/html/sick_leave_system/logos

# اعطِ صلاحيات الكتابة
chmod 755 /var/www/html/sick_leave_system/logos
```

### الخطوة 5: الوصول إلى النظام

افتح متصفحك وانتقل إلى:
```
http://localhost/sick_leave_system/sick_leave_enhanced.php
```

## الاستخدام

### 1️⃣ إضافة المستشفيات

1. انقر على تبويب **"المستشفيات"**
2. أدخل البيانات التالية:
   - **اسم المستشفى (عربي)**: مثال: "مستشفى الملك فهد"
   - **اسم المستشفى (إنجليزي)**: مثال: "King Fahd Hospital"
   - **رقم الترخيص** (اختياري): مثال: "4800031024"
   - **رابط الشعار** (اختياري): رابط صورة الشعار من الإنترنت

3. انقر على **"إضافة مستشفى"**
4. ستظهر المستشفى في الجدول أدناه

### 2️⃣ إضافة الأطباء

1. انقر على تبويب **"الأطباء"**
2. اختر المستشفى (اختياري) - إذا اخترت مستشفى، سيظهر الطبيب مرتبطاً بها
3. أدخل البيانات التالية:
   - **اسم الطبيب (عربي)**: مثال: "محمد عبدالله"
   - **اسم الطبيب (إنجليزي)**: مثال: "Mohammed Abdullah"
   - **المسمى الوظيفي (عربي)**: مثال: "استشاري"
   - **المسمى الوظيفي (إنجليزي)**: مثال: "Consultant"

4. انقر على **"إضافة طبيب"**

### 3️⃣ إضافة المرضى

1. انقر على تبويب **"المرضى"**
2. أدخل البيانات التالية:
   - **اسم المريض (عربي)**: مثال: "أسامة عبدالله"
   - **اسم المريض (إنجليزي)**: مثال: "Osama Abdullah"
   - **رقم الهوية/الإقامة**: مثال: "1019874138"
   - **رقم الهاتف** (اختياري): مثال: "0501234567"

3. انقر على **"إضافة مريض"**

### 4️⃣ إصدار إجازة مرضية

1. انقر على تبويب **"إصدار إجازة"**
2. أدخل البيانات التالية:

   **أ. اختيار البيانات الأساسية:**
   - اختر **المستشفى** (اختياري)
   - اختر **الطبيب** (إذا اخترت مستشفى، سيظهر أطباؤها فقط)
   - اختر **المريض**

   **ب. جهة العمل:**
   - **جهة العمل (عربي)**: مثال: "الى من يهمه الامر"
   - **جهة العمل (إنجليزي)**: مثال: "TO WHOM IT MAY CONCERN"

   **ج. تاريخ ووقت الإصدار:**
   - **تاريخ الإصدار**: اختر التاريخ الميلادي
   - **الوقت**: اختر الوقت (مثال: 09:00)
   - **صباح/مساء**: اختر AM أو PM

   **د. فترة الإجازة:**
   - **تاريخ البداية**: تاريخ بداية الإجازة
   - **تاريخ النهاية**: تاريخ نهاية الإجازة
   
   ⚠️ **ملاحظة مهمة**: النظام سيحسب عدد الأيام تلقائياً!

3. انقر على **"إصدار الإجازة"**
4. ستظهر رسالة نجاح مع رمز الإجازة

### 5️⃣ تحميل PDF

1. انقر على تبويب **"قائمة الإجازات"**
2. ستظهر جميع الإجازات المصدرة
3. انقر على زر **"تحميل PDF"** لأي إجازة
4. سيتم تحميل ملف PDF يحتوي على:
   - ✅ رمز الإجازة
   - ✅ بيانات المريض (عربي/إنجليزي)
   - ✅ بيانات الطبيب (عربي/إنجليزي)
   - ✅ عدد الأيام (مع "s" إذا كان أكثر من يوم)
   - ✅ التواريخ الميلادية والهجرية
   - ✅ جهة العمل
   - ✅ بيانات المستشفى

## الميزات

### ✨ الميزات الرئيسية

#### 1. ربط المستشفيات بالأطباء
- عند اختيار مستشفى عند إصدار إجازة، يظهر فقط أطباء تلك المستشفى
- يمكن إضافة أطباء بدون تحديد مستشفى

#### 2. الأسماء الثنائية (عربي/إنجليزي)
- جميع الأسماء والمسميات يمكن إدخالها بالعربية والإنجليزية
- إذا لم يتم إدخال الاسم الإنجليزي، يظهر فارغ في PDF

#### 3. تحويل التواريخ الهجرية
- عند إصدار إجازة، يتم تحويل التاريخ الميلادي إلى هجري تلقائياً
- يظهر التاريخ الهجري في PDF بجانب الميلادي

#### 4. حساب الأيام
- النظام يحسب عدد الأيام تلقائياً من تاريخ البداية والنهاية
- إذا كانت إجازة يوم واحد: "1 day"
- إذا كانت أكثر: "3 days" (مع إضافة s)

#### 5. إخفاء رقم الترخيص
- إذا لم تكن المستشفى لديها رقم ترخيص، لن يظهر في PDF
- يظهر فقط إذا تم إدخاله

#### 6. رفع الشعارات
- يمكن رفع شعار المستشفى من رابط إنترنت
- يتم حفظ الشعار محلياً على الخادم

## استكشاف الأخطاء

### ❌ المشكلة: "فشل الاتصال بقاعدة البيانات"

**الحل:**
1. تحقق من أن خادم MySQL يعمل
2. تأكد من صحة بيانات الاتصال (المضيف، المستخدم، كلمة المرور)
3. تأكد من أن قاعدة البيانات موجودة
4. تحقق من صلاحيات المستخدم

### ❌ المشكلة: الأسماء العربية تظهر بشكل خاطئ

**الحل:**
1. تأكد من أن charset في قاعدة البيانات هو `utf8mb4`
2. تأكد من أن الملف مشفر بـ UTF-8
3. أضف هذا السطر في بداية الملف:
```php
header('Content-Type: text/html; charset=utf-8');
```

### ❌ المشكلة: لا يعمل تحميل PDF

**الحل:**
1. تأكد من أن `wkhtmltopdf` مثبت على الخادم
2. إذا لم يكن مثبتاً، سيتم عرض HTML بدلاً من PDF
3. لتثبيت wkhtmltopdf:
```bash
# على Ubuntu/Debian
sudo apt-get install wkhtmltopdf

# على CentOS
sudo yum install wkhtmltopdf
```

### ❌ المشكلة: لا تظهر البيانات في الجداول

**الحل:**
1. تأكد من أن الجداول تم إنشاؤها بنجاح
2. افتح أدوات المطور (F12) وتحقق من الأخطاء
3. تحقق من سجل الأخطاء في PHP

### ❌ المشكلة: الشعار لا يتم تحميله من الإنترنت

**الحل:**
1. تأكد من أن الرابط صحيح
2. تأكد من أن cURL مفعل على الخادم
3. تأكد من أن الخادم له وصول للإنترنت
4. جرب رابط آخر

### ❌ المشكلة: الأطباء لا يظهرون عند اختيار مستشفى

**الحل:**
1. تأكد من أنك أضفت أطباء مرتبطين بالمستشفى
2. تحقق من أن معرف المستشفى صحيح
3. افتح أدوات المطور وتحقق من استجابة AJAX

## 💡 نصائح مهمة

### نصيحة 1: النسخ الاحتياطية
قم بعمل نسخة احتياطية من قاعدة البيانات بانتظام:
```bash
mysqldump -u sick_leave_user -p sick_leave_system > backup.sql
```

### نصيحة 2: الأمان
- استخدم كلمة مرور قوية لمستخدم قاعدة البيانات
- استخدم HTTPS في الإنتاج
- قم بتحديث PHP و MySQL بانتظام

### نصيحة 3: الأداء
- أضف indexes لقاعدة البيانات
- استخدم caching للبيانات الثابتة
- قم بتنظيف الإجازات القديمة بانتظام

### نصيحة 4: التخصيص
- يمكنك تغيير الألوان والخطوط في CSS
- يمكنك إضافة حقول جديدة حسب احتياجاتك
- يمكنك تعديل قالب PDF
